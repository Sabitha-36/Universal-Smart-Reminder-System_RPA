Universal Smart Reminder System for Students

📌 Project Overview
The "Universal Smart Reminder System for Students" is a Robotic Process Automation (RPA) project developed using UiPath Studio. It helps students organize academic tasks, manage daily activities, track deadlines, and receive timely email reminders.
The system uses Microsoft Excel to store task details and reminder history, while UiPath automates reminder processing, task tracking, and report generation.

✨ Features
 📚 Academic task management for assignments, exams, and projects
 📅 Daily activity and scheduled reminders
 ⏰ Automated academic deadline reminders
 📧 Email notifications for tasks and activities
 ✅ Academic task completion tracking
 📝 Reminder history and logging
 📊 Student progress report generation
 🖥️ Centralized workflow control through UiPath Forms

🛠️ Technologies Used
 UiPath Studio – Workflow automation
 UiPath Forms – User interaction and dashboard
 Microsoft Excel – Task storage and reminder logs
 Email Activities – Automated notifications
 Microsoft Word – Report generation, if configured

📂 Main Modules
1. Main Workflow and Dashboard
2. Academic Task Management
3. Daily Task Management
4. Academic Reminder Engine
5. Daily Reminder Engine
6. Task Completion Module
7. Reminder Log Module
8. Student Progress Report Module

🚀 How to Run
1. Install UiPath Studio on your computer.
2. Clone or download this repository.
3. Open the project in UiPath Studio using its `project.json` file.
4. Restore the required project dependencies.
5. Configure the Excel file paths and email settings.
6. Verify that all required input files are available.
7. Run the `Main.xaml` workflow.

⚙️ Configuration
Update file paths if the project is moved to another computer.
Configure email activities using your own credentials or an appropriate secure credential store.
Ensure the Excel files contain the required worksheets and column names.
Never upload email passwords, app passwords, or other confidential credentials to GitHub.

🎯 Project Objective
The objective of this project is to reduce missed deadlines, improve time management, automate repetitive reminder activities, and help students monitor their academic progress.

🎓 Project Information
This project was developed for academic purposes as a student productivity and workflow automation solution using UiPath.

📝 Note
The project may require local configuration before execution. Some features depend on the installed UiPath packages, valid Excel file paths, and properly configured email activities.
